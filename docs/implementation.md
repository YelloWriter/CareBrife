## 적용 과정에서 조정한 문구와 동작

- ‘가상 예시’와 샘플 건강정보는 실제 사용자 내용으로 대체했습니다. 입력 전에는 예시를 placeholder로만 표시합니다.
- 브라우저 음성 서비스의 보관 정책은 앱이 통제할 수 없으므로 ‘녹음은 삭제됐어요’를 사용하지 않습니다. 앱이 녹음 파일을 저장하지 않는다는 실제 동작과 브라우저 처리 안내를 표시합니다.
- 크게 보기의 로고와 ‘읽기 화면’이 원본에서 겹치는 부분은 헤더 양쪽 정렬로 해결했습니다.
- 긴 입력은 고정 높이에 가두지 않고 줄바꿈하며 출력 시 다음 페이지로 이어집니다.
- 실제 다운로드 진행률을 표시하며 인위적인 처리 지연을 넣지 않습니다.
- PDF는 기존 방식대로 브라우저 인쇄를 사용합니다. 취소를 성공으로 표시하지 않습니다.
- 원문 의료 문장을 AI가 재작성하지 않고 문장 번호로만 분류합니다. 누락·중복·범위 밖 문장 번호는 오류로 처리합니다.

## 검증과 한계

타입 검사, Next.js 프로덕션 정적 빌드, Playwright 기능 테스트 및 13개 화면 캡처를 확인합니다. 녹음 성공과 5분 제한은 모의 SpeechRecognition 이벤트로 검증합니다. 실제 마이크 인식 품질과 실제 WebGPU 모델 다운로드/추론은 검증 범위에 포함되지 않습니다.

기존 랜딩의 디자인과 베타 신청 링크는 유지했고 구형 입력·미리보기 코드는 제거했습니다. 기존 영어 랜딩은 유지되며 새 Figma 작성 흐름은 한국어입니다. 배포 환경은 기존 Firebase Hosting을 유지합니다. 운영 배포는 별도입니다.
